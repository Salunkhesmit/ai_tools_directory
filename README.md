# My AI Knowledge Universe

## About

My AI Knowledge Universe is a personal directory created to organize and explore AI tools, useful websites, UI resources, code libraries, local AI setups, UI design styles, and learning platforms in one place.

The project features an interactive 3D globe that lets users explore different categories and discover useful resources through a centralized directory.

This project is built using HTML, CSS, Bootstrap 5, JavaScript, Three.js, and Anime.js.

## Features

- **Interactive 3D Globe** — Explore the directory through a rotating 3D globe.
- **7 Organized Categories** — Browse AI tools, websites, UI resources, code libraries, local AI setups, UI design styles, and study resources.
- **Search and Filters** — Find entries using search and category filters.
- **Detailed Entries** — View descriptions, pricing information, access types, tags, and verification status.
- **Direct Website Links** — Open available official links directly from the directory.
- **Centralized Data** — Keep directory entries organized in one data file for easier updates.
- **Responsive Interface** — Browse the directory across desktop, tablet, and mobile screens.
