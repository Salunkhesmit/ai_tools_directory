# 🌌 My AI Knowledge Universe

## 📖 About

My AI Knowledge Universe is a personal directory designed to organize, explore, and discover AI tools, useful websites, UI resources, code libraries, local AI setups, UI design styles, and learning platforms in one centralized space.

The project features an interactive 3D globe that allows users to explore different categories and discover useful digital resources through an immersive and visually engaging directory.

Built to simplify resource discovery and organization, this project brings together a wide range of tools and platforms while providing structured information such as descriptions, pricing, access types, tags, and verification status.

## ✨ Features

- 🌐 **Interactive 3D Globe** — Explore the directory through a rotating and interactive 3D globe.
- 📂 **7 Organized Categories** — Browse AI tools, websites, UI resources, code libraries, local AI setups, UI design styles, and study resources.
- 🔍 **Search and Filters** — Find entries using search functionality and category-based filters.
- 📋 **Detailed Entries** — Explore descriptions, pricing information, access types, tags, and verification status.
- 🔗 **Direct Website Links** — Access available official websites directly from the directory.
- 🗂️ **Centralized Data Management** — Keep directory entries organized in a dedicated data file for easier maintenance and updates.
- 📱 **Responsive Interface** — Explore the directory across desktop, tablet, and mobile devices.
- 🎨 **Immersive UI Experience** — A visually engaging interface combining modern design with interactive 3D elements.

## 🛠️ Technologies Used

HTML5 · CSS3 · Bootstrap 5 · JavaScript · Three.js · Anime.js

## 🎯 Project Type

**Interactive AI & Digital Resources Directory**

A frontend-focused project built to organize useful digital resources, explore interactive 3D web experiences, and practice modern frontend development concepts.
